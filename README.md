## About Me

I'm a Computer Science undergraduate with a particular interest in machine learning, natural language processing, and information retrieval.

I'm interested in understanding how machine learning models work, how well they generalize beyond their development data, and how different modeling and evaluation choices affect their performance.

I've worked on neural model evaluation, document processing, and evidence retrieval. I also enjoy building practical tools alongside my experiments.

## Research Interests

- Neural model generalization and representation learning
- Natural language processing and information retrieval
- Semantic search and retrieval-augmented generation (RAG)
- Machine learning engineering and experimental evaluation
